# The one prompt

> Build a tiny one-button arcade game in a single HTML file: a little rocket
> auto-flies across a starfield, press SPACE or click to flip gravity,
> collect glowing stars for points, dodge the asteroids, speed rises as you
> score, game over screen with restart. Colourful, chunky, plays in a desktop
> browser with no network.

That is the whole brief. Everything in `game/` — the rocket, the stars, the
asteroids, the flip-gravity mechanic — was built from this one prompt, in this
session, by the agent. Open `game/index.html` in a desktop browser and play:
SPACE / click / tap flips gravity.
